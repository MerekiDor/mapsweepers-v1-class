# V1 class for Map Sweepers (w/ Style mechanics)

**Feel free to use this repo as an example/reference** for your custom classes.

Keep in mind though, there's a whole lot of code specifically for custom movement, style and rank. 
Please make sure you don't rip that code out for your custom classes that don't even need it.

*For those who care: this is fully human-made, hence a little bit of a disorganized mess.*
